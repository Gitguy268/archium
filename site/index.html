Hillium

An Arc and Zen style browser with Helium's privacy defaults. Spaces, a liquid-glass command bar, Glance and split view. No ads, no trackers and nothing sent to Google. For Arch Linux and macOS.

Install Source on GitHub

Spaces

Each with its own colours, pinned tabs and folders. Swipe between them.

Today tabs clear themselves

Unpinned tabs go to the archive after the time you choose.

Command bar

⌘T searches every tab in every space, your history and every command, behind real refracting glass.

Glance and split view

⌥-click a link to peek at it. Put up to four pages side by side.

Helium-style privacy

Ghostery's blocker, clean links, HTTPS first, no third-party cookies, GPC, DNS over HTTPS.

Four looks

Arc, Zen, Liquid Glass and Retro 98.

Bring your Arc

Imports spaces, pinned tabs and favourites from Arc and Zen, and bookmarks from Chromium browsers.

For agents too

An opt-in CLI and MCP server, so AI apps can read and open tabs. Private windows stay out of it.

Install on Arch Linux

git clone https://github.com/Gitguy268/hillium && cd hillium/app
npm ci && npm run dist:linux
cp dist/hillium-*.tar.gz ../packaging/arch/ && cd ../packaging/arch
makepkg -si

On macOS, double-click app/start.command. More in the README.
