# Changelog

## 0.1.0 (2026-11-10)

First version.

- Arc and Zen style window: spaces with Zen's colour gradients, favourites, pinned tabs and folders, Today tabs that archive themselves, the command bar, Glance and Peek, split view, compact mode, Boosts and Zap, Little Archium, space rules.
- Four looks: Arc, Zen, Liquid Glass and Retro 98.
- Helium-style privacy on Electron: Ghostery blocking, URL cleaning, HTTPS first, no third-party cookies, trimmed referrers, GPC, no pings, DNS over HTTPS, a plain Chrome user agent, no Google traffic.
- Import from Arc, Zen, Chrome, Brave, Helium, Vivaldi and Chromium.
- ArchiveBox integration, the `archium` CLI and an MCP server for AI agents.
- Arch Linux package (`packaging/arch`), tested in an Arch container.
- Homebrew cask (`brew install --cask gitguy268/tap/archium`) and a self-hosted Flatpak, both built by the release workflow.
